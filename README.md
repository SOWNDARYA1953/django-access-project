1. To Run the code use this commands in terminal
   *cd django_access_project
   * venv\Scripts\activate or  .\venv\Scripts\Activate
   if it is getting error, use the below command
    *Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    *.\venv\Scripts\Activate
2. After install django
   *pip install django
3. After Run this
   *python manage.py runserver
4. Go to:
    http://127.0.0.1:8000/ ---> Login (User/Admin)
    http://127.0.0.1:8000/admin/ ----> To create Items
